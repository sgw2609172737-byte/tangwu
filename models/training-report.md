# 唐五学习型 AI 训练记录

训练完成于 2026-10-06。使用本机 RTX 4070 Laptop GPU、PyTorch 2.14.0+cu130、CUDA 13.0。训练更新实际在 GPU 上执行；对局生成与搜索使用游戏原有 Node.js 引擎。

## 数据与模型

- 本次训练运行共 576 局，全部在步数上限前结束，产生 40,655 条局面样本。
- 首批 192 局由固定节点预算的现有搜索 AI 生成，随后进行 3 轮、每轮 128 局的神经网络引导自我对弈。部分对局混入搜索 AI 作为对手。
- 网络输入 232 个局面特征，隐藏层 128→128；输出 51 个动作的策略分布，以及当前实际操作者的局面价值。
- 合法动作掩码禁止非法动作分配概率。公平正义的不同目标独立编码。相加与再次行动不自动翻转价值；尤里控制按实际操作者计算。
- 策略目标为教师动作或 MCTS 访问分布，价值目标为最终胜负。验证数据以整局划分，未结束的对局不提供虚构胜负标签。
- 训练和对照赛所有原始数据在 `output/training/2026-10-06/run1/`，没有加入 Git。模型 JSON 和浏览器封装在 `models/tangwu-pv.json`、`neural-model.js`。
