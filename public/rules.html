🖐 唐五 · 完整规则手册

双人面对面回合制竞技游戏。本页为权威规则，游戏内一切结算以本页为准。

一、基本设定

  • 2 名玩家面对面，每人两只手，以中国标准数字手势显示数字。
  • 费用手（左手）：显示"实际费用的个位"，实际费用为 0–11 的整数。手势仅显示个位：费用值为 10$ 时显示实心拳、11$ 时显示食指+小指。
  • 技能手（右手）：显示数字 d ∈ {0–9}，决定本回合可选的技能类别，也决定释放技能的费用消耗。
  • 血量 HP：无上限。

三、初始状态

  • 双方实际费用 = 2$，技能手 = 1。
  • 先手随机；先手 HP = 20，后手 HP = 21。

四、回合流程（轮到玩家 X）

  1. 加费用：E ← E+1（含第一回合，回合开始时加；封顶 11，不再增长）。
  2. 技能手相加（强制）：从对方的两只手中必选一只，d ← (d + 对方该手显示数字) mod 10。对方该手数值不变，不消耗费用。被【幻雾】影响时跳过此步。
  3. 行动（可选）：释放 d 对应的一个技能（需 E ≥ d，扣 d 点费用），或空过。
  4. 回合结束，轮到对方。
再次行动：释放【一】【三】【四】【八】【赌命！】后，立即重新执行一次"技能手相加 → 行动"，不额外加费用，仍只能加对方两只手。每回合行动总次数上限 50 次。

五、通用机制

5.1 费用

  • 费用夹在 0–11：加过 11 封顶，减过 0 封底（永不为负）。
  • 【投资】先 +3 再翻倍，同样封顶 11。
  • 技能手相加时费用手按个位取值（10→0，11→1）；扣费按实际费用。

5.2 伤害结算顺序（瞬时伤害，技能释放时即时结算）

  1. 施害方增伤：盈能（下次伤害 +n，一次性）、赌命（每段伤害 +3）。
  2. 受击方有【无敌】：免疫本次伤害、不扣血、+2 血，无敌消失，结算终止（荆棘不触发）。
  3. 受击方扣血。受击方有【荆棘】且为使用后第一次受伤：反弹 ⌈n/2⌉ 给伤害来源；反弹伤害按同规则结算。
  4. 受击方 HP ≤ 0 且有【假人】：触发假人复活。
  5. 胜负检查（双方同时 ≤0 → 平局）。

5.3 延迟 / 持续伤害（dot）

  • 小烈焰：立即 3 伤，施法者下回合开始时自动再造成 2 伤。
  • 淬毒：施法者每放一个攻击技能，目标挂一层"施法者下回合开始时自动扣 1 血"。
  • 七步：目标每回合结束时扣血（见技能表）。
  • dot 伤害最后结算，不触发无敌；不受盈能/赌命增伤；可触发荆棘反弹。
  • 净化：+1 血，并解除自身所有延迟伤害（小烈焰、淬毒）；对七步按"第 1 次降为 −3、第 2 次解除"处理。被冰封时无法使用。

5.4 无敌细则

  • 抵挡下一次直接以你为目标的攻击（伤害），以及与该攻击同技能的附带减益（扣费用等）；抵挡成功 +2 血，无敌消失。
  • 不抵挡：幻雾、七步、冰！的冰冻、尤里的控制、公平正义、dot 伤害（也不会消耗无敌）。
  • 98K 的 114514 秒杀无视无敌。

5.5 假人系统

  • 假人：1 血假人 = 第二条命。有假人时伤害仍打本体；本体 HP ≤ 0 时不死，灵魂转移到假人，复活血量 = 假人血量，手牌/费用/状态全部继承。全局限 1 次。
  • 假人强化：假人 +2 血，可多次叠加；假人作战状态（灵魂已在假人中）下无法使用。
  • 假人唐化：可无限次使用【假人】（优先于"全局限 1 次"），但假人同时存在上限 1——被打掉后可重新召唤。
  • 识破：交换对方本体与假人血量，再对互换后的本体造成 1 伤；对方无假人时互换无效（其余效果照常）。
  • 无视假人的即死：98K 连携秒杀、赌命倒计时归零——血量清零直接败北，不触发假人复活。

5.6 公平正义（去除正面 buff）

可去除的正面 buff 清单：荆棘、无敌、盈能、双倍圣水、呼吸回血、强化、鄙视、淬毒。假人、假人唐化、赌命状态不属于正面 buff，不可去除。

5.7 冰封（冰！）

对方接下来 2 回合：只能 +1 点基础费用，跳过相加与行动，且双倍圣水/呼吸回血/延迟伤害触发均不生效（七步扣血、赌命倒计时照常）。再次被冰封时刷新为 2 回合。

七、胜负判定

  • 任意时刻一方 HP ≤ 0 → 游戏结束（先结算假人复活）。
  • 双方同时 HP ≤ 0 → 平局；否则 HP > 0 的一方获胜。
  • 98K 连携秒杀与赌命倒计时归零为直接败北，无视假人。

八、边界裁定（规则未明说处，本游戏按以下执行）

  1. 先手随机（双方各 50%）。
  2. 费用上限 11、下限 0，所有增减均夹取，永不为负。
  3. 费用 10/11 的手势：10=实心拳、11=食指+小指；相加时均按个位（0/1）。
  4. 再次行动不额外 +1$；每回合行动上限 50 次。
  5. 荆棘触发于"使用后受到的第一次伤害"（含 dot），被无敌抵挡的伤害不触发荆棘。
  6. 嘲讽的判定窗口为"对方的下一个回合"；对方该回合造成的伤害 n<4 时，在对方回合结束时结算反伤 (4−n)；被冰封（无法行动）时 n=0，同样结算。
  7. 幻雾使对方下回合跳过相加；若该回合对方被冰封，幻雾顺延到其下一个正常回合。
  8. 延迟伤害（小烈焰、淬毒）在施法者回合开始时自动结算；若施法者该回合被冰封，则顺延。
  9. dot/延迟伤害不吃盈能与赌命增伤；七步按规则文本执行。
  10. 识破的互换发生在伤害之前；被无敌抵挡时互换不生效（+1 血 +6$ 仍生效）。
  11. 赌命：释放当回合计为第 1 个回合，倒计时在赌命者自己的回合结束时 −1，第 6 个自己的回合结束仍未分胜负 → 血量清零直接败北。
  12. 假人强化可多次叠加；灵魂转移到假人后（假人作战状态）无法再强化。
  13. 鄙视在对方回合开始时判定，双方同时拥有时各自按条件触发。
  14. 公平正义去除列表见 5.6；若对方无正面 buff，公平正义只 +1$。
  15. 淬毒为永久效果（重复释放不叠加，仅刷新），可被公平正义去除；其延迟毒伤不受增伤、可被净化。
  16. 98K 连携要求"连续"数字技能：中间插入其他技能（含空过结束回合）则断链。
  17. 空过立即结束回合；被冰封时无法空过（本就无行动）。
